# 🌿 Ecobud v1.1.3 - Release Notes

🚀 New Features & Updates:
• Lesson Video Credits: Implemented video attribution and credits functionality in educational lessons with validation and mobile UI display.
• Barangay Integration: Added dedicated barangay routes and client hook for fetching barangay records.
• Streamlined Experience & Stats: Enhanced experience routes and admin statistics fetching, alongside accessibility overlay improvements.

🛠️ Bug Fixes & Improvements:
• ID Photo Cleanup: Implemented automated ID photo cleanup and hardened ID verification workflow.
• Version Synchronization: Aligned API, mobile app metadata, and release configurations to 1.1.3 (`APP_LATEST_VERSION` and `APP_MINIMUM_VERSION`).
