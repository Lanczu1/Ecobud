🌿 Ecobud v1.0.9 - Release Notes

🚀 New Features & Updates:
• Barangay Reports & Analytics: Added dedicated barangay-level reports for admins with metrics on Eco Coins redeemed, active resident participation, and localized environmental impact summaries.

• ID Verification System: Added community ID verification with document submission, admin verification dashboard, status notifications, and an Approved ID badge on mobile profiles.

• Admin Report Export: Added direct report export capabilities in the web admin panel to export analytics, activity logs, and redemption data into structured files.

• Give & Get Hub Ratings & Reviews: Added listing ratings, user feedback sections, and transparent rejection reasons on "My Listings" for rejected items.

• Automated Event Attendance & History: Added automated event attendance check-ins and unified user coin and point transaction history tracking.

• Admin Notification Center: Added live admin web notifications and instant alerts for pending submissions, listing reports, and member verifications.

• Announcement Filters & Feed Polish: Added category and status filters for community announcements with faster feed loading.

• Retained Tab Navigation & Performance: Added retained mobile tab views to preserve scroll position and eliminate reload delays when switching between tabs.

🛠️ Bug Fixes & Improvements:
• Give & Get Hub Stability: Fixed issues across item creation, chat message pagination, listing reports handling, and marketplace feed refreshes.

• Barangay Report Date Filtering: Resolved report date range calculation issues for accurate historical and cycle-based queries.

• Notification Dispatch Reliability: Fixed notification payload handling, push token validation, and unread notification badge counters.

• Experience & Leaderboard Corrections: Fixed leaderboard ranking calculations, user profile snapshot consistency, and pagination issues.

• Mobile Asset & Feed Optimization: Added cursor pagination, image prefetching, refined skeleton loading states, and reduced low-end device lag.

• Codebase Cleanup: Removed obsolete test fixtures, duplicate mock files, and unused legacy assets across web and mobile projects.

• Version Alignment: Updated API, mobile, and landing metadata to 1.0.9 and incremented the Android version code to 7.
