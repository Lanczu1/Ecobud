# 🌿 Ecobud v1.0.9 - Release Notes

🚀 New Features & Updates:

• Admin Report Export: Added export functionality for admin reports.
• Give & Get Hub Rating & Review Lists: Added rating list, feedback, and reject reasons on listings.
• ID Verification Flow: Added new verification UI, enhanced routes, and status handling for community member identity checks.
• Barangay Reports & Dates: Refined barangay reports display, dates, and Eco Coins redemption changes.
• Automated Event Attendance & History: Added automatic attendance tracking for eco-events along with updated coins/points history display.
• Announcement Filters & Performance Optimizations: Added announcement filtering, performance optimizations across mobile screens, and cleanups.

🛠️ Bug Fixes & Improvements:

• Give & Get Hub Bug Fixes: Fixed multiple issues across listing creation, status updates, ratings, and moderation.
• Notifications & Admin Controls: Improved notification routing and delivery, streamlined admin/moderator actions.
• Mobile App Performance: General mobile app optimizations, reduced duplicate code, and cleaned up unnecessary files.
• App Version Alignment: Updated API, mobile, and landing release metadata to 1.0.9, incremented Android version code to 7, and updated default environment version thresholds.
