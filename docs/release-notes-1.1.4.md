# 🌿 Ecobud v1.1.4 - Release Notes

🚀 New Features & Updates:
• Event Report Summaries: Implemented dedicated event report summaries endpoint with pagination, search, and live attendance and reward metrics aggregation.
• Dual-AI Challenge Image Recognition: Enhanced challenge photo verification with Gemini vision prioritization, intelligent hedging, and Mistral vision fallback.
• Enhanced Marketplace & Swap Service: Upgraded Give & Get swap conversations with request status handling, unread message caching, and real-time updates.

🛠️ Bug Fixes & Improvements:
• Low-End Device Animation Optimization: Refined particle animations and overlay rendering performance for smooth transitions on entry-level mobile devices.
• Background Refresh Queues: Added debounced refresh queue utility to avoid redundant in-flight network requests across notifications and redemption flows.
• Query Performance & Badge Milestones: Optimized user data retrieval and milestone queries across API routes.
• Version Synchronization: Aligned API, mobile app metadata, and release configurations to 1.1.4 across all project manifests.
