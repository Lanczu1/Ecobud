# EcoBud Android APK Downloads

Ilagay dito ang iyong built `.apk` file:
Halimbawa:
`apps/landing/public/downloads/ecobud-beta.apk`

Kapag inilagay mo rito ang file, awtomatikong mada-download ng testers ang file sa link na:
`/downloads/ecobud-beta.apk`

> **Paalala:** Ang `.apk` extension ay naka-ignore sa root `.gitignore` (`*.apk`) kaya hindi ito magpapadumi o magpapabigat sa Git repository ninyo.
